## English

This release upgrades image OCR on Windows and improves search responsiveness and clipboard panel behavior on macOS.

### Added

- Added PaddleOCR-based image recognition on Windows, with “Speed first” and “Accuracy first” models that work offline after download.
- Added OCR model download progress, verification, repair, and removal controls in Settings.
- Added direct links to OCR settings when a model needs to be downloaded or repaired.

### Improvements

- Reduced search input lag when clipboard history contains long text, while keeping the full content available for copying and viewing.
- Improved Chinese input method support so searches wait until text composition is complete.
- Fixed outdated search and pagination results appearing after the search term changes.
- Fixed the clipboard list not scrolling correctly after reopening the panel on macOS.
- Improved Settings loading and navigation, and updated translations for OCR setup and model management.

## 简体中文

本次更新升级了 Windows 图片 OCR，并改善了搜索流畅度和 macOS 剪贴板面板的使用体验。

### 新增

- Windows 图片识别接入 PaddleOCR，提供“速度优先”和“精度优先”两种模型，下载后可离线使用。
- 设置中新增 OCR 模型下载进度、文件校验、修复和移除功能。
- 模型未下载或需要修复时，可直接跳转到 OCR 设置处理。

### 改进

- 优化剪贴板历史包含长文本时的搜索输入卡顿，复制和详情查看仍保留完整内容。
- 改善中文输入法兼容性，选词完成后再触发搜索。
- 修复修改关键词后，旧搜索或分页结果混入当前列表的问题。
- 修复 macOS 重新打开面板后，剪贴板列表无法正常滚动的问题。
- 优化设置页面的加载与导航，并补充 OCR 设置和模型管理的多语言文案。
