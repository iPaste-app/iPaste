## English

This release improves file copying and image previews, and adds an app center with an authenticator.

### Added

- Capture and paste a single copied file, with separate actions to copy or paste its path.
- Show file names, type icons, sizes, and thumbnails for supported image files in cards and preview windows.
- Open the app center and manage authenticator accounts, with independent shortcuts and quick code pasting.

### Improvements

- Keep file references read-only and show clear errors when the source file is moved, deleted, or inaccessible.
- Preserve captured image data, reuse duplicate captures, and load cached thumbnails on demand.
- Improve Windows clipboard access coordination and image paste performance.
- Refine authenticator account layout and quick-paste interactions.

## 简体中文

本次更新改进文件复制粘贴和图片预览，并新增内置验证器的应用中心。

### 新增

- 支持记录和粘贴单个复制的文件，也可单独复制或粘贴文件路径。
- 在卡片和预览窗口中显示文件名、类型图标、大小，以及受支持图片文件的缩略图。
- 新增应用中心和验证器账户管理，支持独立快捷键与验证码快捷粘贴。

### 改进

- 文件引用保持只读，源文件被移动、删除或无法访问时显示明确提示。
- 保留采集到的图片数据，复用重复图片记录，按需加载并缓存缩略图。
- 改进 Windows 剪贴板访问协调和图片粘贴性能。
- 优化验证器账户布局和快捷粘贴交互。
